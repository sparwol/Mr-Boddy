    How the blast radius score works

    For each party, the toolkit collects every system it connects to, plus every system in a network segment it can reach by VPN or site-to-site link. It adds up the weight of each data type those systems hold, then multiplies by the party's highest privilege and its riskiest way of connecting. The weights below are policy choices in the toolkit's policy file, not an industry standard.

    For AI services, reach comes only from the OAuth scopes users granted (mail and calendar scopes reach email; file and site scopes reach file storage). Data a department might have pasted in is labeled "possible" and counts half, or in full when large uploads were seen.
